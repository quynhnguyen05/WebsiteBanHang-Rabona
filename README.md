RABONA SPORT - E-commerce Website

📌 Introduction

Rabona Sport is a web-based e-commerce application designed to manage and sell sports products.
The system supports both customers and administrators in performing daily operations efficiently.

🎯 Objectives

* Build a basic online shopping platform
* Practice web development and system analysis skills
* Understand business flows in e-commerce systems

👤 User Roles

1. Customer

* Register / Login
* Browse products
* Add to cart
* Place orders

2. Admin

* Manage products
* Manage orders
* Manage customers
* View revenue reports

⚙️ Features

* User Authentication (Login/Register)
* Product Management
* Order Management
* Customer Management
* Revenue Report Dashboard

🧠 Business Analysis Insight

This system solves the problem of manual sales management by:
* Automating order processing
* Centralizing product management
* Improving customer experience
* Providing revenue tracking for business decisions

📊 Use Case Summary

Actor: Customer, Admin

Customer:
* Register/Login
* Browse products
* Place orders

Admin:
* Manage products
* Manage orders
* View reports

🏗️ System Architecture

* Backend: Python (Django)
* Frontend: HTML, CSS
* Database: SQLite

📊 Business Flow (BA perspective)

1. Customer registers an account
2. Customer logs in
3. Customer selects products
4. Customer places an order
5. Admin processes the order
6. System updates order status

🖥️ How to Run the Project

```bash
python manage.py runserver
```

Then open: http://127.0.0.1:8000/

📁 Project Structure

`store/` - Main application
`templates/` - UI templates
`views.py` - Business logic
